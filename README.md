# 카페 공명 대시보드 — GitHub 배포 묶음

카페사업팀 대시보드입니다. **데이터는 들어 있지 않고**, 두 구글 시트를 열 때마다(그리고 켜 둔 동안 5분마다) 읽어서 보여줍니다.

| 시트 | 누가 입력 | 누가 보나 |
|---|---|---|
| 지점 입력 시트 (카페공명_지점입력시트, 9탭) | 각 지점 · 연남 베이커리 · 합정 로스터리 | 지점끼리 서로 봄 |
| 본사 시트 (카페공명_본사시트, 15탭) | 본사 | 본사만 |

대시보드 주소와 비밀번호도 본사만 압니다. 자세한 절차는 함께 받은 **운영 매뉴얼**을 따르세요.

## 파일

| 파일 | 역할 | 고치나? |
|---|---|---|
| `index.html` | 화면 | 새 버전을 받을 때만 통째로 교체 |
| `app.js` | 코드 전체 | 새 버전을 받을 때만 통째로 교체 |
| `sw.js` · `manifest.webmanifest` · `icon-*.png` · `favicon.png` | 앱 설치·오프라인용 | 새 버전을 받을 때만 |
| `.nojekyll` | GitHub Pages가 파일을 그대로 올리게 함(안 올라가도 괜찮음) | 없음 |
| **`config.js`** | **설정 한 줄 — 이 묶음에는 없음.** 초기 설정 화면에서 만든 내용으로 GitHub에서 직접 만듦 | 비밀번호·시트를 바꿀 때만 |

## 처음 올리기

1. 두 엑셀 템플릿을 구글 드라이브에 올려 각각 *Google Sheets로 저장*. 탭 이름·1행 제목은 바꾸지 않습니다.
2. 두 시트 모두 *공유 → 일반 액세스: 링크가 있는 모든 사용자 · 뷰어*. 편집자는 지점 시트 = 지점·베이커리·로스터리 인원, 본사 시트 = 본사 인원만.
3. 새 저장소(예: `cafe-dashboard`, Public)를 만들고 **압축을 푼 폴더 안의 파일들**을 올립니다(zip 파일 그대로 X, 폴더째 X).
4. *Settings → Pages → Branch: main / (root) → Save*. 1~2분 뒤 `https://<계정>.github.io/cafe-dashboard/` 가 열립니다.
5. 그 주소를 열면 *초기 설정* 화면 → 두 시트 주소 · (권장) 탭 주소 · 비밀번호 → *연결 확인* → *설정 코드 만들기* → *코드 복사*.
6. 저장소에서 *Add file → Create new file* → 이름 `config.js` → 복사한 한 줄 붙여넣기 → *Commit changes*. 1~2분 뒤 새로고침하고 비밀번호로 들어갑니다.

## 바꿀 때

- **비밀번호·시트 주소:** 대시보드 주소 뒤에 `#setup` → 새 코드 → `config.js` 열기 → 연필(Edit) → 내용을 새 줄로 바꾸고 *Commit changes*.
- **새 버전(기능 추가·수정):** 새 묶음의 파일을 *Add file → Upload files*로 올리면 같은 이름은 덮어써집니다. `config.js`는 묶음에 없으니 그대로 남습니다. **`config.js`는 지우지 마세요.**
- **새 지점:** 본사 시트 `01_지점`에 한 줄 + 지점 입력 시트 `99_목록` A열에 같은 이름. 코드는 고치지 않습니다.

## 보안 원칙

- 시트 주소는 `config.js` 안에 **비밀번호로 암호화된 형태로만** 들어갑니다. 대시보드 주소나 코드가 알려져도 비밀번호 없이는 본사 시트를 찾을 수 없습니다. 비밀번호는 지점에서 짐작하기 어려운 10자 이상으로.
- 화면은 스크립트를 이 저장소의 파일에서만 읽도록 막아 두었습니다(CSP). 지점 시트 칸에 누가 HTML이나 스크립트를 적어도 실행되지 않습니다.
- **이 저장소에 엑셀 템플릿이나 스냅샷 HTML을 올리지 마세요.** 실제 매출·손익이 들어 있습니다.
- 본사 시트 주소를 메신저로 돌리지 말고, 급여·계정·연락처는 두 시트 어디에도 넣지 않습니다.
- **지점 시트에서 본사 시트를 IMPORTRANGE로 불러오지 마세요.** 한 번 허용하면 지점 시트 편집자 누구나 본사 시트 전체를 읽을 수 있습니다.

|---|---|
| 초기 설정 화면만 계속 나옴 | 저장소에 `config.js`가 있는지(이름 철자·확장자), 1~2분 기다렸는지 |
| "구글 시트를 읽지 못했습니다" | 두 시트의 일반 액세스가 *링크가 있는 모든 사용자 · 뷰어* 인지 → `#setup` 의 *연결 확인* |

| 비밀번호를 잊음 | `#setup` 에서 새 비밀번호로 코드를 다시 만들어 `config.js` 교체 (데이터는 시트에 그대로) |
| 고쳤는데 화면이 그대로 | 1~2분 뒤 새로고침, 그래도 같으면 Ctrl+Shift+R(맥은 Cmd+Shift+R) |
